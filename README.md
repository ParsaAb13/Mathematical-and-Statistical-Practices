# 📐 Mathematical and Statistical Practices

This repository is dedicated to practical exercises using Python to enhance core skills in mathematical and statistical concepts, bridging the gap between theoretical math and data science applications.

---

## 📌 Section 1: Overview & Learning Roadmap

The learning path in this repository is structured into three progressive modules:

### 🎯 Core Modules:
1. **01. Descriptive Statistics:** Data summarization, central tendency, dispersion metrics, distribution shapes, and exploratory data analysis (EDA).
2. **02. Inferential Statistics:** Probability distributions, hypothesis testing (t-tests, ANOVA, Chi-Square), confidence intervals, and statistical modeling.
3. **03. Machine Learning Foundations:** Mathematical principles behind ML algorithms, including linear algebra, multivariate calculus, optimization, and foundational models.
